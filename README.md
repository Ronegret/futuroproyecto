# Futuro Proyecto

Web de servicios y precios en **[futuroproyecto.rodrigonegrete.es](https://futuroproyecto.rodrigonegrete.es)**: webs, automatizaciones, chatbots y agentes de voz con IA, contenido para redes y portales/CRM a medida.

- Sitio estático: un `index.html` autocontenido + `assets/` (posters y vídeos de proyectos).
- Fondo animado en canvas, mapa conceptual SVG, calculadora de presupuesto y chatbot "Nexo" (sin claves ni API externas).
- Despliegue: Vercel (estático, sin build).
